# 🌸 She Can Foundation Website

A simple and responsive frontend webpage created for the **She Can Foundation** internship task.
The website is designed to spread awareness about women empowerment with a clean modern UI, animations, and dark mode support.

## ✨ Features

* Responsive single-page layout
* Modern UI design
* About section
* Women empowerment image section
* Dark mode toggle
* Smooth animations and hover effects
* Clean and beginner-friendly code

## 🛠️ Built With

* HTML
* CSS

## 📂 Sections Included

* Navigation Bar
* About Section
* Footer

## 🌙 Extra Features

* Dark mode support
* Floating image animation
* Responsive design for mobile devices

## 📖 About

This project was developed as part of an internship frontend task for **She Can Foundation** to demonstrate basic frontend development skills using HTML, CSS, and JavaScript.
